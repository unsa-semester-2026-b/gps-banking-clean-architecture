⚙️ Fundamentación Arquitectónica del Proyecto

Este software fue elegido e implementado porque satisface estrictamente los principios de Clean Architecture y Domain-Driven Design (DDD). El dominio empresarial no tiene acoplamiento a frameworks web (Express), bibliotecas de base de datos o herramientas externas. Toda la lógica de invariantes (fondos, divisas, integridad de montos) está protegida dentro del Agregado Account y los Value Objects Money. Esto garantiza máxima eficiencia, bajo costo operativo y portabilidad total para empresas financieras e industriales del Perú.
